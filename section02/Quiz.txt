다음 중 JavaScript에서 Falsy 값이 아닌 것은 무엇인가요?
- []
- [] (빈 배열), {} (빈 객체) 등은 명확한 Falsy 7가지에 포함되지 않아 Truthy로 평가됩니다. Falsy는 undefined, null, 0, -0, NaN, "", 0n뿐입니다.

논리 AND(`&&`) 연산에서 첫 번째 피연산자가 Falsy이면 어떻게 되나요?
- 두 번째 피연산자를 평가하지 않고 첫 번째 Falsy 값을 즉시 반환한다.
- && 연산자는 첫 번째 값이 Falsy이면 뒤 값을 확인하지 않아도 결과가 Falsy임이 명확하므로, 뒤의 피연산자는 평가하지 않고 첫 번째 Falsy 값을 바로 반환하는 단락 평가가 일어납니다.

person 객체의 name과 age 속성을 각각 n, a 변수로 할당하는 객체 구조 분해 문법은?
- let { name: n, age: a } = person;
- 객체 구조 분해 시 속성 이름을 새 변수 이름으로 변경하려면 { 원본속성명: 새변수명 } 형태를 사용합니다. name 속성을 n으로, age 속성을 a로 할당하려면 { name: n, age: a }가 맞습니다.

함수 호출 시 배열의 모든 요소를 개별 인자로 전달할 때 쓰는 문법은 무엇인가요?
- Spread 연산자
- Spread 연산자(...)는 배열이나 객체의 요소를 펼쳐서 개별 값으로 만들 때 사용합니다. 함수 호출 시 배열 앞에 ...을 붙이면 배열의 요소들이 함수의 각각의 인자로 전달됩니다.

원시 타입과 객체 타입이 값을 저장하고 복사하는 방식의 핵심 차이는 무엇인가요?
- 원시: 실제 값, 객체: 참조 값
- 원시 타입은 변수에 값이 직접 저장/복사되는 반면, 객체 타입은 값이 메모리 다른 곳에 저장되고 변수에는 그 위치를 가리키는 참조 값이 저장/복사됩니다. 이 때문에 객체는 가변적입니다.

배열의 '값'을 순서대로 반복할 때 인덱스 없이 주로 사용하는 반복문은 무엇인가요?
- for...of
- for...of 반복문은 배열, Map, Set 등 반복 가능한 객체의 요소를 값 자체로 순회할 때 사용합니다. 객체의 속성을 순회하는 for...in과는 다릅니다.

배열의 각 요소를 변형하여 '새로운 배열'을 만들 때 쓰는 대표적인 메서드는?
- map
- map() 메서드는 배열의 모든 요소를 순회하며 콜백 함수의 실행 결과를 모아 새로운 배열로 반환합니다. 원본 배열을 변경하지 않고 각 요소를 변형할 때 사용됩니다.

원본 배열의 '맨 앞'에 요소를 추가하고 새 길이를 반환하는 메서드는?
- unshift()
- unshift()는 배열 맨 앞에 요소를 추가하고 새 길이를 반환하는 메서드입니다. push()는 맨 뒤에 추가하고, pop()은 맨 뒤 요소를 제거, shift()는 맨 앞 요소를 제거합니다.

자바스크립트가 싱글스레드임에도 비동기 처리를 사용하는 주된 이유는?
- 오래 걸리는 작업 때문에 프로그램이 멈추는 것을 방지하기 위해.
- 자바스크립트는 싱글스레드 환경이라 오래 걸리는 작업이 발생하면 다음 작업이 멈추는 블로킹 현상이 일어납니다. 비동기는 기다리지 않고 다른 작업을 먼저 처리하게 해 프로그램 효율을 높입니다.

'콜백 지옥'을 개선하고 비동기 코드를 읽기 쉽게 만드는 최신 문법은?
- Async/Await
- Async/Await는 Promise 문법 위에 구축된 구문으로, 비동기 코드를 마치 동기 코드처럼 순차적으로 작성할 수 있게 해줍니다. 복잡한 콜백 중첩 문제인 콜백 지옥을 해결하는 데 유용합니다.
